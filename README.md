# Welcome to my Python repository!

## Purpose of this repository
I have created this repository to document my Python learning journey. As a retired web developer / systems analyst I am learning Python for fun, so this repository will contain projects that interest me, not necessarily projects that would interest a future employer.

## Organization
I have broken out my Python exercises into several folders: - Scripts: short automations that run in the terminal - Apps: small to large applications I have built that run on the desktop - Web Apps: small to large web applications I have built that run within a browser

Each script or app will be foldered with a README.md explaining how it works and if additional setup is needed in order to run it.
